Lamp Guide 1.2.4

开始使用
1. 从桌面或开始菜单打开 Lamp Guide。
2. 在“服务”页面查看本地 API 地址与当前端口。
3. 在“渠道”页面登录需要使用的渠道，或在“供应商”添加自己的 API。
4. 在“聚合”搜索模型，展开模型后管理渠道参与状态并查看积分倍率。
5. 在“Agent”页面连接支持的客户端。

界面
右上角的太阳 / 月亮按钮用于切换日间和夜间模式。
切换带淡入动画，保留当前页面与搜索内容；重启后记住所选模式。
聚合模型支持搜索、启用优先排序和底部分页。
“全部停用 / 全部启用”只控制对应模型的渠道候选。

签到
在“渠道 → 签到中心”点击“一键签到”，可手动领取已开启渠道的每日奖励。
支持设置自动执行时间；程序关闭或休眠期间不执行。
新接入的 AStudio、AutoClaw 国内/国际版、超级麦吉/MagiCrew 国际版为试验接入，
目前通过本机插件导入或手填凭据登录，尚未完成真实账号端到端验证。
上游需要验证码或人工处理时，请按界面提示在官方服务完成。

安装与更新
安装器面向当前 Windows 用户，默认安装到：
%LOCALAPPDATA%\Programs\Lamp Guide
以后安装新版时，选择相同目录即可更新。
安装或卸载前请正常关闭 Lamp Guide。
WebView2 缺失时，安装器使用内附的微软官方离线安装程序补齐。

数据与兼容
为沿用原有账号和设置，数据路径继续保留：
%APPDATA%\zen-gate
WebView2 与模式设置继续使用：
%LOCALAPPDATA%\ZenUI\webview
原有 ZEN_GATE_HOME 等环境变量和客户端协议标识继续兼容。
这些目录属于用户数据，不随卸载自动删除。

卸载
在 Windows“设置 > 应用 > 已安装的应用”选择 Lamp Guide，
或者使用开始菜单中的“卸载 Lamp Guide”。
卸载会移除程序、快捷方式和指向此安装目录的开机启动项，保留用户配置。
微软 WebView2 是共享组件，卸载 Lamp Guide 时会保留它。
